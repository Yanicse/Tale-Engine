# Novel packs

One folder per novel, `novels/<slug>/`, created by `novel init <slug>`.

```
novels/<slug>/
  novel.json       title, language, tracked NPCs, currencies, world rules, opening scene
  character.json   the player's character
  theme.json       the look and the wording of the reading page
  chronology.json  optional: the episodes the clocks and arcs cite
  clocks.json      optional: the secret clocks of the factions (the chronicler)
  arcs.json        optional: the arcs of the world, followed off screen
  sources/         your book files (ignored by git)
  text/            extracted pages, text/vNN.jsonl (ignored by git)
  work/            canon build work files (ignored by git)
  canon.sqlite     the canon, generated by `novel canon build` (ignored by git)
```

`novel campaign new <slug>` copies the pack into the campaign. **Later edits of `novel.json`, `character.json` or
`theme.json` apply to campaigns created afterwards**, not to a campaign that already exists.

Run `novel validate <slug>` at any time: it lists every problem by file and key. Without it the engine silently
drops invalid values; with it you see them. `novel campaign new` refuses a pack that has errors.

## novel.json

| Key | Content |
| --- | --- |
| `title` | the novel's title, used as the page title unless `theme.json` sets one |
| `language` | `en`, `fr`, `fr-FR`, `French`... It is the language of the narration, and of the page when a language pack exists (`en`, `fr`) |
| `tracked_npcs` | list of `{id, name, place, goal}`: each gets one private off-screen step in the world agenda, so they pursue their goal while the player acts elsewhere |
| `currency_rates` | `{"gold": {"silver": 20}}`: official conversion rates the narrator must apply |
| `currencies` | `{"gold": {"label": "gold coins", "initial_balance": 10}}`: tracked player money. Currencies named only in conversion rates start at zero. Balances change through validated payments, purchases and sales; conversion rates do not automatically convert a purse. Inventory operations work even with no currencies. |
| `world_rules` | list of sentences given to the narrator as written (30 at most, 400 characters each) |
| `opening` | `{place, scene}`: the place where the story starts and the first scene, recorded as the first narration |

`tracked_npcs` and `world_rules` are the universal way to keep a universe's own rules out of the engine: nothing else
in the engine or the page knows a novel by name.

Currency ids become `player_<id>` resource counters. They cannot reuse reserved health, mana, combat or
death-prevention counters, including when the optional `character.json` is absent. The same restriction applies
to both sides of every conversion rate.

## character.json

| Key | Content |
| --- | --- |
| `name` | the character's name (`{name}` in the page texts) |
| `hp_max` | maximum hit points, a whole number from 1 (default 100) |
| `mana_max` | maximum mana, a non-negative integer (default 100); use 0 for a character without magic |
| `description` | a short description, saved with the campaign and sent to the narrator |
| `rules` | optional passives, abilities, costs and limits: see [Character sheets](character-sheets.md) |

## theme.json

| Key | Content |
| --- | --- |
| `preset` | `auto` (follows the fictional hour), `classic`, `dark-fantasy`, `arcane`, `frost`, `scifi` |
| `title`, `subtitle`, `input_hint` | page title (`{name}` is the character), subtitle, hint in the input box; leave empty for the language default |
| `clock` | `false` hides the fictional clock |
| `colors` | `background`, `text`, `muted`, `line`, `card`, `accent`, `gold`, `blood`, `player`; values `#hex` or `rgb()` / `rgba()` |
| `labels` | any text of the page by key, see [Prompts and languages](prompts-and-languages.md) |
| `icons` | `{"objects" \| "abilities" \| "places": [["word\|other word", "icon-name"]]}`, matched on the words of an item's name or description; icon names are the files of `novel_engine/resources/icons` |

See [Reader page](reader.md) for how these are served.

## World files (optional)

Every campaign keeps a register of **creations** (details the narrator invents: NPCs, places, quests, reputations) and a
periodic **planner** that summarizes the story every 20 narrator replies. A pack can add a world that moves on its own:

| File | Content |
| --- | --- |
| `chronology.json` | `{"nodes": [{"id", "title", "phase", "relative_time"}], "edges": [{"before", "after"}]}`: the episodes that clocks and arcs may cite as `chronology:<id>` |
| `clocks.json` | a list of at most 8 clocks `{id, faction, goal, segments (3 to 10), progression, status: "in_progress", signs, event, origin: "canon" or "invention", reason, references}`. A clock drawn from the canon cites a `chronology:<id>` reference |
| `arcs.json` | `{"version": 1, "arcs": [{id, title, nodes, dependencies, opening_days, end_days, steps, clock}], "outside_arcs": {}}`. Every chronology node belongs to an arc or is listed in `outside_arcs` with a reason |

Having `clocks.json` or `chronology.json` installs the chronicler; `arcs.json` (which needs `chronology.json`) also installs the
arcs registry. The chronicler reviews the world on the first turn, after seven fictional days, and after a long ellipsis;
each review is one extra model call and the player's message always comes first. `novel validate` installs these files in an
empty database and reports each mistake with its file. The campaign keeps its own copy of the chronology: later edits
of the pack apply to new campaigns only. `novel example --world` installs a complete example.

## An example to copy

`novel example` installs a complete pack. Its files are in `novel_engine/assets/examples/lantern_bay/`:
`novel.json` (two tracked NPCs, a currency rate, two world rules, an opening scene), `character.json` (a passive and two
abilities with costs) and `theme.json` (a preset, labels, icons).
