# Code of conduct

This project is a place to build and play with interactive stories. Everyone is welcome, whatever their level or background.

## What we expect

- Be kind and patient. Criticize the code and the ideas, never the person.
- Assume good intent, and ask when something is unclear.
- Keep discussions on topic and constructive.

## What is not accepted

- Harassment, insults, discrimination or personal attacks of any kind.
- Publishing someone else's private information.
- Sharing copyrighted books or their extracted text in issues or pull requests.

## Enforcement

The maintainer may edit, hide or remove comments, issues and pull requests that break these rules, and may block repeat offenders.
To report a problem, open an issue or contact the maintainer, [@Yanicse](https://github.com/Yanicse), on GitHub.

This text applies in every project space, and when someone represents the project in public.
